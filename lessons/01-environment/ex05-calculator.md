# תרגיל 5: מחשבון במצב אינטראקטיבי

לפייתון יש מצב שבו מקלידים פקודה אחת, והיא מבוצעת מיד.
זה נקרא **מצב אינטראקטיבי**, והוא מצוין לניסויים מהירים.

---

## חלק א: להיכנס ולצאת

בטרמינל, הקלידו רק את שם הפקודה, בלי שם של קובץ:

```bash
python
```

יופיע סימן כזה, שאומר שפייתון מחכה לפקודה:

```text
>>>
```

נסו להקליד חישוב ולחצו על אנטר:

```python
2 + 3
```

כדי לצאת מהמצב האינטראקטיבי ולחזור לטרמינל הרגיל, הקלידו:

```python
exit()
```

אם הסימן לא מופיע ונראה שהטרמינל תקוע, כנראה שאתם בחלון נפרד של גיט באש ולא בעורך. עברו לטרמינל שבתוך העורך, או נסו:

```bash
winpty python
```

## חלק ב: פעולות חשבון

נסו כל אחת מהשורות הבאות. **לפני** שמריצים כל שורה, נחשו מה תהיה התוצאה.

```python
7 + 2
7 - 2
7 * 2
7 / 2
7 // 2
7 % 2
7 ** 2
2 + 3 * 4
(2 + 3) * 4
2 ** 100
10 / 0
0.1 + 0.2
```

### שאלות

1. מה ההבדל בין חילוק עם לוכסן אחד לבין חילוק עם שני לוכסנים?
2. מה עושה סימן האחוז? חשבו גם את החישובים הבאים, ונסחו כלל:

   ```python
   17 // 5
   17 % 5
   ```

3. איך אפשר לבדוק בעזרת סימן האחוז אם מספר הוא זוגי?
4. מה מיוחד בתוצאה של שתיים בחזקת מאה? האם המחשבון בטלפון שלכם היה מציג אותה כך?
5. התוצאה של החיבור האחרון לא בדיוק שווה ל-0.3. למה לדעתכם?

## חלק ג: לתת שמות לערכים

אפשר לשמור ערך תחת שם, ולהשתמש בשם הזה בהמשך. זה נקרא **משתנה**.

```python
voltage = 5
resistance = 220
voltage / resistance
```

### תרגילים

חשבו בעזרת פייתון. השתמשו במשתנים כדי שיהיה קל לשנות את הערכים.

1. שלושה נגדים מחוברים בטור: 220, 330 ו-1000 אוהם. מה ההתנגדות השקולה?
2. שני נגדים מחוברים במקביל: 220 ו-330 אוהם. מה ההתנגדות השקולה?
3. נורית מחוברת לספק של 5 וולט דרך נגד של 220 אוהם. המתח על הנורית הוא 2 וולט. מה הזרם במעגל, במיליאמפר?
4. מה ההספק שמתפזר על הנגד מהסעיף הקודם, במיליוואט?
5. נגד של 1000 אוהם מחובר ל-12 וולט. מה ההספק עליו? האם נגד של רבע וואט יחזיק?

## חלק ד: שעות, דקות ושניות

1. כמה שניות יש ביממה? חשבו בעזרת כפל.
2. נתון מספר השניות הבא:

   ```python
   seconds = 10000
   ```

   בעזרת שני סוגי החילוק שלמדתם, חשבו כמה שעות, כמה דקות וכמה שניות זה.
   התשובה צריכה להיות: 2 שעות, 46 דקות ו-40 שניות.
3. שנו את מספר השניות לערך אחר, ובדקו שהחישוב שלכם עדיין עובד.
