## חלק א: כפל של טקסט

```python

```

## חלק ב: צורות

צרו קובץ חדש בשם הבא:

```text

```

השתמשו בכפל של טקסט, בלי להקליד את כל הכוכביות ידנית. כתבו תוכנית שמדפיסה:

1. מלבן ברוחב 10 ובגובה 4:

   ```text
   **********
   **********
   **********
   **********
   ```

2. מלבן חלול באותו גודל:

   ```text
   **********
   *        *
   *        *
   **********
   ```

3. משולש בגובה 5:

   ```text
   *
   **
   ***
   ****
   *****
   ```

4. משולש שמיושר לצד השני:

   ```text
       *

   ```
