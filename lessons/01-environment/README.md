# מפגש 1: סביבת העבודה

## מטרות המפגש

בסוף המפגש תדעו:

- להתקין ולהגדיר את כלי העבודה של הקורס.
- לנווט במערכת הקבצים מתוך הטרמינל, בלי עכבר.
- ליצור, להעתיק, להעביר ולמחוק קבצים ותיקיות מהטרמינל.
- לכתוב תוכנית פייתון ראשונה ולהריץ אותה.

## הצגה בסוף המפגש

בסוף המפגש אחד הסטודנטים יציג, בערך 3 דקות, על המחשב שלו:

- את מבנה התיקיות שבנה בתרגיל 3, ואת הפקודות שבהן השתמש.
- תוכנית פייתון אחת שכתב, הרצה שלה מהטרמינל, והסבר מה כל שורה עושה.
- דבר אחד שלא עבד בדרך, ואיך פתרתם אותו.

שמרו לעצמכם רשימה קצרה של בעיות שנתקלתם בהן ואיך פתרתם אותן. זה יעזור בהצגה.
