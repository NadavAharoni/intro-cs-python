# תרגיל 11: הורדת חומרי הקורס עם גיט

תרגיל בונוס. גיט הוא כלי לניהול גרסאות של קוד. נלמד אותו לעומק בהמשך.
בינתיים נשתמש בו לדבר אחד: להוריד למחשב את כל חומרי הקורס, ולעדכן אותם בכל שבוע.

---

## חלק א: שכפול

כל חומרי הקורס נמצאים במאגר באתר גיטהאב.
הורדה של מאגר למחשב נקראת **שכפול**.

1. עברו לתיקיית הבית:

   ```bash
   cd ~
   ```

2. שכפלו את מאגר הקורס:

   ```bash
   git clone https://github.com/NadavAharoni/intro-cs-python.git
   ```

3. היכנסו לתיקייה שנוצרה, והסתכלו מה יש בה:

   ```bash
   cd intro-cs-python
   ls
   ls lessons
   ```

### שאלות

1. מה שם התיקייה שנוצרה? מאיפה הגיע השם הזה?
2. השוו את התוכן שלה לדף של המאגר באתר. האם יש הבדלים?
3. יש בתיקייה תיקייה מוסתרת. מה השם שלה? רמז: חזרו לחלק ב בתרגיל 2.

---

## חלק ב: לקרוא את התרגילים בעורך

1. פתחו את התיקייה בעורך:

   ```bash
   code .
   ```

2. פתחו את אחד מקובצי התרגילים.
3. כדי לראות אותו מעוצב, כמו באתר, הקישו:

   ```text
   Ctrl+Shift+V
   ```

---

## חלק ג: עדכון בכל שבוע

כל שבוע יתווספו למאגר תרגילים חדשים. כדי לקבל אותם, נכנסים לתיקייה ומריצים:

```bash
cd ~/intro-cs-python
git pull
```

## חשוב

אל תשמרו את העבודה שלכם בתוך התיקייה המשוכפלת.
אם תשנו שם קבצים, העדכון השבועי עלול להיכשל.
את כל העבודה שלכם שמרו בתיקייה שיצרתם בתרגיל 2.
