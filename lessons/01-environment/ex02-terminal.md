# תרגיל 2: ניווט בטרמינל

הטרמינל הוא דרך לתת פקודות למחשב באמצעות טקסט, במקום עכבר.
מתכנתים משתמשים בו כל הזמן, ולכן נתרגל אותו כבר מההתחלה.

עבדו בטרמינל שבתוך העורך.
החליפו תפקידים בין נהג לנווט אחרי כל חלק.
רשמו את התשובות לשאלות בקובץ טקסט או על דף. תצטרכו אותן בהצגה.

---

## חלק א: איפה אני?

בכל רגע הטרמינל "נמצא" בתיקייה מסוימת, שנקראת התיקייה הנוכחית.
הפקודה הבאה מדפיסה את המסלול המלא של התיקייה הנוכחית:

```bash
pwd
```

### שאלות

1. מה הודפס?
2. פתחו את סייר הקבצים של חלונות ומצאו את אותה תיקייה. איך כתוב שם המסלול שלה?
3. מה ההבדלים בין שתי הדרכים לכתוב את המסלול? שימו לב לכיוון הלוכסנים ולאות של הכונן.

---

## חלק ב: מה יש כאן?

הפקודה הבאה מציגה את התוכן של התיקייה הנוכחית:

```bash
ls
```

לפקודות רבות אפשר להוסיף **אפשרויות**, שמתחילות במקף. נסו:

```bash
ls -l
ls -a
ls -la
```

### שאלות

1. מה ההבדל בין הפלט של כל אחת מארבע הפקודות?
2. הפקודה עם האות a מציגה פריטים שהשם שלהם מתחיל בנקודה. אלה קבצים מוסתרים. מצאו לפחות שניים כאלה.
3. בפלט של הפקודה עם האות l, איך אפשר לדעת מה תיקייה ומה קובץ? רמז: הסתכלו על התו הראשון בכל שורה.

---

## חלק ג: לזוז בין תיקיות

הפקודה להחלפת התיקייה הנוכחית:

```bash
cd
```

אחריה כותבים לאן לעבור. יש כמה שמות מיוחדים שכדאי להכיר:

<div dir="rtl">

| סימן | משמעות |
|---|---|
| <code dir="ltr">.</code> | התיקייה הנוכחית |
| <code dir="ltr">..</code> | התיקייה שמעל התיקייה הנוכחית |
| <code dir="ltr">~</code> | תיקיית הבית שלכם |
| <code dir="ltr">/</code> | השורש של מערכת הקבצים |

</div>

הריצו את הפקודות הבאות אחת אחרי השנייה. אחרי כל אחת, הריצו את הפקודה שמדפיסה איפה אתם, ושימו לב איך זה משתנה.

```bash
cd ~
cd ..
cd ..
cd /c
ls
cd ~
```

### מסלול מוחלט ומסלול יחסי

- **מסלול מוחלט** מתחיל בלוכסן, ומתאר את המיקום מהשורש. הוא עובד מכל מקום.
- **מסלול יחסי** לא מתחיל בלוכסן, ומתאר את המיקום ביחס לתיקייה הנוכחית.

```bash
# absolute path - works from anywhere
cd /c/Users

# relative path - depends on where you are now
cd ..
```

### שאלות

1. כשאתם בתיקיית הבית, מה קורה אם מריצים את הפקודה להחלפת תיקייה בלי שום דבר אחריה?
2. מה קורה אם מריצים את הפקודה עם מקף אחריה? נסו את זה פעמיים ברצף.

   ```bash
   cd -
   ```

3. נסו לעבור לתיקייה שלא קיימת. מה הודעת השגיאה?

---

## חלק ד: ליצור תיקיות וקבצים

עכשיו ניצור את תיקיית העבודה של הקורס. בה תשמרו את כל מה שתכתבו בקורס.

```bash
cd ~
mkdir intro-cs
cd intro-cs
mkdir lesson01
cd lesson01
pwd
```

יצירת קובץ ריק:

```bash
touch notes.txt
ls
```

כתיבת טקסט לתוך קובץ, והצגת התוכן שלו:

```bash
echo "Hello from the terminal" > notes.txt
cat notes.txt
```

### שאלות

1. הריצו שוב את פקודת הכתיבה לקובץ, אבל עם טקסט אחר. מה קרה לטקסט הקודם?
2. עכשיו נסו עם שני סימני גדול-מ במקום אחד. מה ההבדל?

   ```bash
   echo "Another line" >> notes.txt
   cat notes.txt
   ```

## חלק ה: להעתיק, להעביר, למחוק

```bash
# copy a file
cp notes.txt notes-backup.txt

# rename (move) a file
mv notes-backup.txt old-notes.txt

# delete a file
rm old-notes.txt
```

**זהירות:** מחיקה בטרמינל היא סופית. הקובץ לא עובר לסל המיחזור.

למחיקת תיקייה ריקה:

```bash
rmdir folder-name
```

למחיקת תיקייה עם כל התוכן שלה. היזהרו מאוד עם הפקודה הזו:

```bash
rm -r folder-name
```

### שאלות

1. צרו תיקייה בשם הבא, והעבירו לתוכה את הקובץ שיצרתם קודם:

   ```text
   archive
   ```

2. מה קורה אם מנסים למחוק עם הפקודה למחיקת תיקייה ריקה תיקייה שיש בה קבצים?

## חלק ו: קיצורי דרך שיחסכו לכם הרבה זמן

<div dir="rtl">

| מקש או פקודה | מה זה עושה |
|---|---|
| מקש הטאב | משלים שם של קובץ או תיקייה. הקלידו כמה אותיות ולחצו |
| חץ למעלה | מחזיר את הפקודה הקודמת |
| <code dir="ltr">clear</code> | מנקה את המסך |
| <code dir="ltr">explorer .</code> | פותח את התיקייה הנוכחית בסייר הקבצים |
| <code dir="ltr">code .</code> | פותח את התיקייה הנוכחית בעורך |

</div>

נסו כל אחד מהם לפחות פעם אחת.

### שימו לב לשפת המקלדת

פקודות מקלידים תמיד באנגלית. אם במקום פקודה הופיעו אותיות בעברית, החליפו שפה בעזרת הקיצור:

```text
Alt+Shift
```

4. הציגו את התוכן של תיקיית הארכיון בלי להיכנס אליה.
