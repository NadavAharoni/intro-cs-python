# תרגיל 8: מחשבון לחוק אוהם

תרגיל בונוס. כאן תשתמשו בכל מה שלמדתם היום: קבצים, משתנים, קלט, פלט וחשבון.

נזכיר את הנוסחאות:

```text
V = I * R
P = V * I
```

---

## חלק א: חישוב זרם

צרו קובץ חדש בשם הבא:

```text
ohm.py
```

כתבו תוכנית ש:

1. מבקשת מהמשתמש מתח בוולטים.
2. מבקשת התנגדות באוהם.
3. מדפיסה את הזרם באמפר, וגם במיליאמפר.
4. מדפיסה את ההספק בוואט.

המספרים יכולים להיות עשרוניים, לכן השתמשו בפקודה שהופכת טקסט למספר עשרוני.

דוגמה להרצה:

```text
Voltage (V): 9
Resistance (Ohm): 330
Current: 0.02727 A = 27.27 mA
Power: 0.24545 W
```

### טיפ: עיגול

כדי לעגל מספר לכמה ספרות אחרי הנקודה, משתמשים בפקודה הבאה:

```python
round(0.0272727, 5)
```

## חלק ב: נגד לנורית

כתבו תוכנית חדשה בשם הבא:

```text
led.py
```

התוכנית מחשבת איזה נגד צריך לחבר לנורית:

1. מבקשת את מתח הספק.
2. מבקשת את מתח הנורית.
3. מבקשת את הזרם הרצוי דרך הנורית, במיליאמפר.
4. מדפיסה את ההתנגדות הדרושה באוהם.
5. מדפיסה את ההספק שיתפזר על הנגד, במיליוואט.

בדיקה: ספק של 5 וולט, נורית של 2 וולט, וזרם של 20 מיליאמפר. ההתנגדות צריכה לצאת 150 אוהם.

---

## חלק ג: מחלק מתח

כתבו תוכנית שמקבלת מתח כניסה ושני נגדים, ומדפיסה את מתח היציאה של מחלק המתח:

```text
Vout = Vin * R2 / (R1 + R2)
```

## אתגר

נגדים נמכרים רק בערכים מסוימים. בסדרה הנפוצה, אלה הערכים בין 100 ל-1000:

```text
100, 120, 150, 180, 220, 270, 330, 390, 470, 560, 680, 820, 1000
```

בתוכנית של חלק ב, הדפיסו גם את הערך הסטנדרטי הקרוב ביותר שאינו קטן מהערך שחישבתם.
את זה עוד לא למדנו, אבל אפשר לנסות לחפש איך עושים את זה.
