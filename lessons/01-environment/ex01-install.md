# תרגיל 1: התקנת סביבת העבודה

בתרגיל הזה כל אחד מבני הזוג מתקין את הכלים על המחשב שלו.
עבדו במקביל ועזרו זה לזה. אם אחד נתקע, השני עוצר ועוזר.

התקינו בסדר הזה בדיוק, כי כל כלי משתמש בקודם לו.

---

## חלק א: עורך הקוד

1. היכנסו לאתר:

   ```text
   https://code.visualstudio.com
   ```

2. הורידו את הגרסה לחלונות והריצו את קובץ ההתקנה.
3. במסך האפשרויות, ודאו שהאפשרויות הבאות מסומנות:

   ```text
   Add "Open with Code" action to Windows Explorer file context menu
   Add "Open with Code" action to Windows Explorer directory context menu
   Add to PATH
   ```

4. סיימו את ההתקנה ופתחו את העורך, כדי לוודא שהוא עולה.

---

## חלק ב: פייתון

החל מגרסה 3.14, הדרך המומלצת להתקין פייתון בחלונות היא כלי שנקרא:

```text
Python install manager
```

1. היכנסו לאתר:

   ```text
   https://www.python.org/downloads/
   ```

2. הורידו את הכלי והתקינו אותו.
   אפשרות נוספת: לחפש אותו בחנות של מיקרוסופט ולהתקין משם.
3. פתחו חלון חדש של הטרמינל של חלונות. מקישים על מקש חלונות, מקלידים את המילה הבאה ולוחצים על אנטר:

   ```text
   powershell
   ```

4. הקלידו את הפקודה הבאה, שמתקינה את הגרסה האחרונה של פייתון:

   ```bash
   py install
   ```

   אם נשאלתם שאלות בזמן ההתקנה, למשל האם להוסיף תיקייה למשתנה הסביבה, ענו כן.
5. סגרו את חלון הטרמינל, פתחו חלון חדש, והקלידו:

   ```bash
   python --version
   ```

   אמורה להופיע שורה כמו זו:

   ```text
   Python 3.15.0
   ```

### אם משהו לא עובד

- **נפתחת החנות של מיקרוסופט במקום פייתון:**
  פתחו את תפריט ההתחלה וחפשו את ההגדרה הבאה.
  ודאו שהאפשרויות של פייתון שם מופעלות.

  ```text
  Manage app execution aliases
  ```

- **הפקודה לא מזוהה:** סגרו את כל חלונות הטרמינל ופתחו מחדש. אם זה לא עוזר, הפעילו מחדש את המחשב.

---

## חלק ג: גיט לחלונות

1. היכנסו לאתר:

   ```text
   https://git-scm.com
   ```

2. הורידו את הגרסה לחלונות והריצו את קובץ ההתקנה.
3. ברוב המסכים אפשר להשאיר את ברירת המחדל וללחוץ הלאה. יש שני מסכים שבהם כדאי לשנות:
   - במסך שבו בוחרים עורך ברירת מחדל, בחרו:

     ```text
     Use Visual Studio Code as Git's default editor
     ```

   - במסך שעוסק בשם הענף הראשי, בחרו באפשרות לשנות אותו, והקלידו:

     ```text
     main
     ```

---

## חלק ד: הגדרת העורך

1. סגרו את העורך לגמרי ופתחו אותו מחדש, כדי שיזהה את גיט.
2. התקינו את התוסף של פייתון:
   - לחצו על סמל התוספים בסרגל השמאלי, או הקישו:

     ```text
     Ctrl+Shift+X
     ```

   - חפשו את התוסף הבא, וודאו שהיצרן שלו הוא מיקרוסופט:

     ```text
     Python
     ```

   - לחצו על כפתור ההתקנה.
3. הגדירו את "גיט באש" כטרמינל ברירת המחדל:
   - הקישו:

     ```text
     Ctrl+Shift+P
     ```

   - הקלידו ובחרו:

     ```text
     Terminal: Select Default Profile
     ```

   - בחרו:

     ```text
     Git Bash
     ```

4. פתחו טרמינל בתוך העורך. מהתפריט העליון בוחרים בתפריט הטרמינל ואז בטרמינל חדש, או מקישים:

   ```text
   Ctrl+`
   ```

   בצד ימין של חלון הטרמינל צריך להופיע השם "באש".

---

## חלק ה: בדיקה סופית

בטרמינל שבתוך העורך, הריצו את שלוש הפקודות הבאות, אחת אחרי השנייה:

```bash
python --version
git --version
code --version
```

כל פקודה צריכה להדפיס מספר גרסה, ולא הודעת שגיאה.

## הערה חשובה

אם שם המשתמש שלכם בחלונות כתוב בעברית או מכיל רווחים, ספרו למרצה. זה עלול לגרום לבעיות בהמשך, ועדיף לטפל בזה עכשיו.
כדי לבדוק, הריצו בטרמינל:

```bash
echo $HOME
```
