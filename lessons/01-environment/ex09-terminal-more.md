# תרגיל 9: עוד כוח בטרמינל

תרגיל בונוס. הכוח האמיתי של הטרמינל הוא שאפשר לחבר פקודות קטנות זו לזו, ולבנות מהן דברים גדולים.

עבדו בתוך תיקיית המפגש.

---

## חלק א: עזרה

כמעט לכל פקודה יש הסבר מובנה. מקבלים אותו כך:

```bash
ls --help
```

### שאלות

1. מצאו בהסבר איזו אפשרות ממיינת את הקבצים לפי גודל.
2. מצאו איזו אפשרות מציגה את הגדלים ביחידות קריאות, כמו קילובייט.
3. נסו את שתי האפשרויות ביחד.

---

## חלק ב: קובץ עם הרבה שורות

הפקודה הבאה מייצרת את המספרים מ-1 עד 100, ושומרת אותם בקובץ:

```bash
seq 1 100 > numbers.txt
```

נסו את הפקודות הבאות, והסבירו מה כל אחת עושה:

```bash
cat numbers.txt
head numbers.txt
head -n 3 numbers.txt
tail -n 5 numbers.txt
wc -l numbers.txt
grep 7 numbers.txt
sort -r numbers.txt
```

### שאלות

1. מה הבעיה בפלט של הפקודה האחרונה? מצאו בהסבר המובנה שלה איך לתקן אותה.
2. כמה מספרים בין 1 ל-100 מכילים את הספרה 7?

---

## חלק ג: צינורות

הקו האנכי מעביר את הפלט של פקודה אחת להיות הקלט של הפקודה הבאה. זה נקרא **צינור**.

```bash
grep 7 numbers.txt | wc -l
seq 1 1000 | grep 99
ls -l | grep txt
```

### תרגילים

כתבו שורה אחת, עם צינורות, שעושה כל אחד מהדברים הבאים:

1. מדפיסה רק את השורות 10 עד 15 של קובץ המספרים.
2. סופרת כמה מספרים בין 1 ל-1000 מסתיימים בספרה 3.
3. סופרת כמה קבצים ותיקיות יש בתיקיית הבית שלכם.

---

## חלק ד: פלט של תוכנית לתוך קובץ

אפשר לשמור את הפלט של תוכנית פייתון בקובץ, בדיוק כמו פלט של כל פקודה אחרת:

```bash
python hello.py > output.txt
cat output.txt
```

---

## חלק ה: חיפוש קבצים

הפקודה הבאה מוצאת את כל קובצי הפייתון בתוך תיקיית הקורס, כולל בתיקיות פנימיות:

```bash
find ~/intro-cs -name "*.py"
```

### שאלות

1. מה הכוכבית עושה בפקודה?
2. מצאו את כל קובצי הטקסט בתיקיית הקורס.
3. בעזרת צינור, ספרו כמה קובצי פייתון כתבתם היום.

---

## חלק ו: היסטוריה

הטרמינל זוכר את כל הפקודות שהרצתם:

```bash
history
```

שמרו את 30 הפקודות האחרונות שהרצתם בקובץ. הקובץ הזה יעזור לכם בהצגה בסוף המפגש.
