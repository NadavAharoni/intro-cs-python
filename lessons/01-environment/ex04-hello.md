# תרגיל 4: התוכנית הראשונה

הגיע הזמן לכתוב קוד!
תוכנית בפייתון היא קובץ טקסט רגיל, שהסיומת של השם שלו היא:

```text
.py
```

---

## חלק א: לכתוב ולהריץ

1. בטרמינל, עברו לתיקיית המפגש ופתחו אותה בעורך:

   ```bash
   cd ~/intro-cs/lesson01
   code .
   ```

   אם העורך שואל אם אתם סומכים על התיקייה, אשרו.
2. צרו קובץ חדש בשם הבא. אפשר מהתפריט בעורך, או מהטרמינל עם הפקודה שלמדתם ליצירת קובץ ריק.

   ```text
   hello.py
   ```

3. כתבו בקובץ את השורה הבאה בדיוק:

   ```python
   print("Hello, World!")
   ```

4. שמרו את הקובץ. קיצור המקשים לשמירה:

   ```text
   Ctrl+S
   ```

5. בטרמינל שבתוך העורך, הריצו את התוכנית:

   ```bash
   python hello.py
   ```

ברכות, כתבתם והרצתם את התוכנית הראשונה שלכם!

### שימו לב: שמירה

אפשר להפעיל שמירה אוטומטית מתפריט הקובץ:

```text
File > Auto Save
```

## חלק ב: הרצה מתוך העורך

בפינה הימנית העליונה של העורך יש כפתור הרצה בצורת משולש.
לחצו עליו והסתכלו בטרמינל.

### שאלות

1. איזו פקודה העורך הריץ בשבילכם? היא נראית קצת אחרת מהפקודה שאתם הרצתם. מה ההבדל?
2. מה היתרון בהרצה מהטרמינל, ומה היתרון בכפתור?

## חלק ג: להדפיס עוד דברים

הוסיפו לקובץ את השורות הבאות, שמרו והריצו:

```python
print("My name is Python")
print()
print("Line one")
print("Line two")
print("A", "B", "C")
print(3 + 4)
print("3 + 4")
```

### שאלות

1. מה עושה פקודת ההדפסה בלי שום דבר בתוך הסוגריים?
2. מה ההבדל בין שתי השורות האחרונות? למה הפלט שלהן שונה?
3. כשמדפיסים כמה ערכים מופרדים בפסיקים, מה מופיע ביניהם בפלט?

## חלק ד: הערות

כל מה שמופיע אחרי סימן סולמית לא מבוצע. זו **הערה**, שנועדה לאנשים שקוראים את הקוד.

```python
# This program prints a greeting
print("Hello")  # this part is ignored too
# print("This line will not run")
```

### שאלות

1. הוסיפו בראש הקובץ הערה עם השמות של שניכם.
2. הפכו את אחת משורות ההדפסה להערה, והריצו. מה השתנה?
   טיפ: בעורך, הקיצור הבא הופך שורה להערה ובחזרה:

   ```text
   Ctrl+/
   ```

## חלק ה: לשבור בכוונה

כדאי להכיר את הודעות השגיאה כבר עכשיו. כל פעם שנו דבר אחד, הריצו, ותקנו בחזרה:

1. מחקו את המירכאות הסוגרות באחת השורות.
2. כתבו את פקודת ההדפסה עם אות ראשונה גדולה:

   ```python
   Print("Hello")
   ```

3. מחקו את הסוגר הסוגר באחת השורות.
4. הוסיפו רווח בתחילת אחת השורות.

### שאלות

1. לכל שגיאה: מה סוג השגיאה שהופיע בשורה האחרונה של ההודעה?
2. האם ההודעה הצביעה על השורה הנכונה?
