# תרגיל 1, דרך חלופית: התקנה בפקודות

זו דרך חלופית להתקנה שבתרגיל 1. במקום להוריד קובצי התקנה מאתרים ולעבור על הרבה מסכים, מתקינים הכל בעזרת פקודות.
הפקודות משתמשות בכלי של מיקרוסופט להתקנת תוכנות, שמגיע עם חלונות.

- אם כבר התקנתם הכל לפי תרגיל 1 והכל עובד, אין צורך בדף הזה.
- אם ההתקנה לפי תרגיל 1 נתקעה באמצע, אפשר להמשיך מכאן. מה שכבר מותקן לא יותקן שוב.

---

## חלק א: פתיחת הטרמינל של חלונות

1. לחצו על מקש חלונות, והקלידו:

   ```text
   powershell
   ```

2. לחצו על אנטר. **אין** צורך להריץ כמנהל מערכת.
3. בדקו שכלי ההתקנה קיים:

   ```powershell
   winget --version
   ```

   אמור להופיע מספר גרסה. אם מופיעה הודעה שהפקודה לא מוכרת, התקינו מהחנות של מיקרוסופט את האפליקציה הבאה, ונסו שוב:

   ```text
   App Installer
   ```

---

## חלק ב: התקנה בפקודה אחת

הפקודה הבאה מורידה ומריצה סקריפט שמתקין את כל הכלים של הקורס ומגדיר אותם. העתיקו אותה לחלון הטרמינל ולחצו על אנטר:

```powershell
irm https://raw.githubusercontent.com/NadavAharoni/intro-cs-python/main/setup/install-windows.ps1 | iex
```

- ההתקנה לוקחת כמה דקות. בזמן ההתקנה של גיט, חלונות ישאל אם לאשר שינויים במחשב. אשרו.
- בסוף, הסקריפט מדפיס את הגרסאות של כל הכלים. אם מופיעה שורה עם המילה הבאה, קראו מה כתוב בה:

  ```text
  PROBLEM
  ```

- בסיום, סגרו את כל החלונות של הטרמינל ושל העורך, ופתחו אותם מחדש.

רוצים לדעת מה הסקריפט עושה לפני שמריצים אותו? זה רעיון טוב. אפשר לקרוא אותו כאן: [הסקריפט](../../setup/install-windows.ps1).
מותר גם לבקש מכלי בינה מלאכותית להסביר אותו.

אחרי שהסקריפט סיים, דלגו לחלק ד.

---

## חלק ג: התקנה צעד אחרי צעד

זו אותה התקנה, בלי הסקריפט. הריצו כל פקודה בנפרד, וחכו שתסתיים לפני הפקודה הבאה.
אם כלי ההתקנה שואל אם אתם מסכימים לתנאי השימוש, הקלידו את האות Y ולחצו על אנטר.

1. עורך הקוד:

   ```powershell
   winget install --exact --id Microsoft.VisualStudioCode --source winget --override "/VERYSILENT /NORESTART /MERGETASKS=!runcode,addcontextmenufiles,addcontextmenufolders,associatewithfiles,addtopath"
   ```

2. פייתון. הפקודה מתקינה את פייתון רק עבור המשתמש שלכם, ומוסיפה אותו לנתיב החיפוש של הפקודות:

   ```powershell
   winget install --exact --id Python.Python.3.14 --source winget --override "/quiet InstallAllUsers=0 PrependPath=1 Include_launcher=0 Include_test=0"
   ```

3. גיט לחלונות, עם ההגדרות של הקורס. חלונות ישאל אם לאשר שינויים במחשב. אשרו.

   ```powershell
   winget install --exact --id Git.Git --source winget --override "/VERYSILENT /NORESTART /NOCANCEL /SP- /COMPONENTS=icons,ext\reg\shellhere,assoc,assoc_sh,gitlfs,windowsterminal /o:EditorOption=VisualStudioCode /o:DefaultBranchOption=main /o:PathOption=Cmd"
   ```

4. סגרו את חלון הטרמינל, ופתחו חלון חדש. זה נחוץ כדי שהחלון יכיר את הפקודות החדשות.
5. התוסף של פייתון לעורך:

   ```powershell
   code --install-extension ms-python.python
   ```

6. הגדירו את "גיט באש" כטרמינל ברירת המחדל בעורך, כמו בסעיף 3 של חלק ד בתרגיל 1.

---

## חלק ד: גיט באש בטרמינל של חלונות

1. פתחו את האפליקציה הבאה:

   ```text
   Terminal
   ```

2. לחצו על החץ הקטן שליד הלשונית, למעלה. ברשימה אמורה להופיע האפשרות הבאה:

   ```text
   Git Bash
   ```

3. אם היא לא מופיעה, סגרו את הטרמינל לגמרי ופתחו אותו שוב.
4. אם היא עדיין לא מופיעה, הריצו את הסקריפט מחלק ב. הוא מוסיף את האפשרות אם היא חסרה, ולא משנה שום דבר שכבר מותקן.

---

## חלק ה: בדיקה סופית

פתחו טרמינל חדש, והריצו את שלוש הפקודות הבאות:

```bash
python --version
git --version
code --version
```

כל פקודה צריכה להדפיס מספר גרסה. גרסת פייתון צריכה להיות 3.12 או חדשה יותר.

ודאו גם שכל הבדיקות מרשימת הבדיקה שבסוף תרגיל 1 עוברות.

---

## אם משהו לא עובד

### פייתון מדפיס גרסה ישנה

כנראה שמותקנת אצלכם גרסה ישנה של פייתון, וחלונות מוצא אותה לפני הגרסה החדשה. הפקודה הבאה מציגה את כל הגרסאות שחלונות מוצא, לפי הסדר שבו הוא מחפש:

```powershell
where.exe python
```

אפשר להסיר את הגרסה הישנה בהגדרות של חלונות, בדף של האפליקציות המותקנות. אם אתם לא בטוחים מה להסיר, היעזרו במרצה.

### מופיעה הודעה שמציעה להתקין פייתון מהחנות

```text
Python was not found; run without arguments to install from the Microsoft Store
```

סגרו את כל חלונות הטרמינל ופתחו חלון חדש. אם ההודעה עדיין מופיעה, הריצו שוב את הפקודה שמתקינה את פייתון.

### פקודה של כלי ההתקנה נכשלה

הריצו אותה שוב. אם היא נכשלת שוב, צלמו את המסך והראו למרצה.
