# תרגיל 1, דרך חלופית: התקנה מתוך עורך הקוד

זו דרך חלופית להתקנה שבתרגיל 1, בשני שלבים בלבד:

1. מתקינים את עורך הקוד, כמו בתרגיל 1.
2. בטרמינל שבתוך העורך, מריצים פקודה אחת שמתקינה ומגדירה את כל השאר.

הפקודה משתמשת בכלי של מיקרוסופט להתקנת תוכנות, שמגיע עם חלונות. לא צריך להוריד קבצים מאתרים ולא צריך לעבור על מסכי התקנה.

- אם כבר התקנתם הכל לפי תרגיל 1 והכל עובד, אין צורך בדף הזה.
- אם ההתקנה לפי תרגיל 1 נתקעה באמצע, אפשר להמשיך מכאן. מה שכבר מותקן לא יותקן שוב.
- אם שום דבר לא עובד במחשב שלכם, יש גם [דרך חירום](ex01-codespaces.md): סביבת עבודה מלאה בתוך הדפדפן.

---

## חלק א: עורך הקוד

התקינו את עורך הקוד לפי [חלק א בתרגיל 1](ex01-install.md).
אם כבר מותקן אצלכם עורך הקוד, דלגו לחלק ב.

---

## חלק ב: פקודה אחת

1. פתחו את עורך הקוד.
2. פתחו טרמינל בתוך העורך: מהתפריט העליון בוחרים בתפריט הטרמינל ואז בטרמינל חדש. בצד ימין של חלון הטרמינל אמור להופיע השם הבא:

   ```text
   powershell
   ```

   אם מופיע שם אחר, למשל באש, לחצו על החץ הקטן שליד סימן הפלוס בחלון הטרמינל, ובחרו:

   ```text
   PowerShell
   ```

3. בדקו שכלי ההתקנה קיים:

   ```powershell
   winget --version
   ```

   אמור להופיע מספר גרסה. אם מופיעה הודעה שהפקודה לא מוכרת, התקינו מהחנות של מיקרוסופט את האפליקציה הבאה, ונסו שוב:

   ```text
   App Installer
   ```

4. העתיקו את הפקודה הבאה לטרמינל, ולחצו על אנטר:

   ```powershell
   irm https://raw.githubusercontent.com/NadavAharoni/intro-cs-python/main/setup/install-windows.ps1 | iex
   ```

   - ההתקנה לוקחת כמה דקות. בזמן ההתקנה של גיט, חלונות ישאל אם לאשר שינויים במחשב. אשרו.
   - בסוף, הפקודה מדפיסה את הגרסאות של כל הכלים. אם מופיעה שורה עם המילה הבאה, קראו מה כתוב בה:

     ```text
     PROBLEM
     ```

5. **סגרו את העורך לגמרי**, כולל כל החלונות שלו, ופתחו אותו מחדש. בלי זה, העורך לא יכיר את הכלים החדשים.

רוצים לדעת מה הפקודה מריצה, לפני שמריצים אותה? זה רעיון טוב. אפשר לקרוא את הסקריפט כאן: [הסקריפט](../../setup/install-windows.ps1).
מותר גם לבקש מכלי בינה מלאכותית להסביר אותו.

### מה הסקריפט עושה

- מתקין את פייתון ואת גיט לחלונות, עם ההגדרות של הקורס.
- מתקין את התוסף של פייתון לעורך.
- מגדיר את "גיט באש" כטרמינל ברירת המחדל בעורך.
- מוסיף את "גיט באש" לאפליקציית הטרמינל של חלונות.

---

## חלק ג: בדיקה

1. בעורך, פתחו טרמינל חדש. הפעם, בצד ימין של חלון הטרמינל אמור להופיע השם "באש".
2. הריצו את שלוש הפקודות הבאות:

   ```bash
   python --version
   git --version
   code --version
   ```

   כל פקודה צריכה להדפיס מספר גרסה. גרסת פייתון צריכה להיות 3.12 או חדשה יותר.
3. ודאו גם שכל הבדיקות מרשימת הבדיקה שבסוף תרגיל 1 עוברות.

אם הטרמינל בעורך עדיין לא באש, הגדירו אותו ידנית, כמו בסעיף 3 של חלק ד בתרגיל 1.

---

## חלק ד: התקנה צעד אחרי צעד

זו אותה התקנה, בלי הסקריפט. השתמשו בה רק אם הסקריפט לא עבד, או אם אתם רוצים לראות כל שלב בנפרד.
הריצו כל פקודה בנפרד בטרמינל של העורך, וחכו שתסתיים לפני הפקודה הבאה.
אם כלי ההתקנה שואל אם אתם מסכימים לתנאי השימוש, הקלידו את האות Y ולחצו על אנטר.

1. פייתון. הפקודה מתקינה את פייתון רק עבור המשתמש שלכם, ומוסיפה אותו לנתיב החיפוש של הפקודות:

   ```powershell
   winget install --exact --id Python.Python.3.14 --source winget --override "/quiet InstallAllUsers=0 PrependPath=1 Include_launcher=0 Include_test=0"
   ```

2. גיט לחלונות, עם ההגדרות של הקורס. חלונות ישאל אם לאשר שינויים במחשב. אשרו.

   ```powershell
   winget install --exact --id Git.Git --source winget --override "/VERYSILENT /NORESTART /NOCANCEL /SP- /COMPONENTS=icons,ext\reg\shellhere,assoc,assoc_sh,gitlfs,windowsterminal /o:EditorOption=VisualStudioCode /o:DefaultBranchOption=main /o:PathOption=Cmd"
   ```

3. התוסף של פייתון לעורך:

   ```powershell
   code --install-extension ms-python.python
   ```

4. סגרו את העורך לגמרי ופתחו אותו מחדש.
5. הגדירו את "גיט באש" כטרמינל ברירת המחדל בעורך, כמו בסעיף 3 של חלק ד בתרגיל 1.

אם גם עורך הקוד עצמו לא הותקן, אפשר להתקין אותו באותה דרך, מחלון של הטרמינל של חלונות:

```powershell
winget install --exact --id Microsoft.VisualStudioCode --source winget --override "/VERYSILENT /NORESTART /MERGETASKS=!runcode,addcontextmenufiles,addcontextmenufolders,associatewithfiles,addtopath"
```

## אם משהו לא עובד

### פייתון מדפיס גרסה ישנה

כנראה שמותקנת אצלכם גרסה ישנה של פייתון, וחלונות מוצא אותה לפני הגרסה החדשה. הפקודה הבאה, בטרמינל של חלונות, מציגה את כל הגרסאות שחלונות מוצא, לפי הסדר שבו הוא מחפש:

```powershell
where.exe python
```

אפשר להסיר את הגרסה הישנה בהגדרות של חלונות, בדף של האפליקציות המותקנות. אם אתם לא בטוחים מה להסיר, היעזרו במרצה.

### מופיעה הודעה שמציעה להתקין פייתון מהחנות

```text
Python was not found; run without arguments to install from the Microsoft Store
```

סגרו את העורך לגמרי ופתחו אותו מחדש. אם ההודעה עדיין מופיעה, הריצו שוב את הפקודה מחלק ב.

### פקודה של כלי ההתקנה נכשלה

הריצו אותה שוב. אם היא נכשלת שוב, צלמו את המסך והראו למרצה.
בינתיים, אפשר להמשיך לעבוד ב[סביבת העבודה בדפדפן](ex01-codespaces.md).
