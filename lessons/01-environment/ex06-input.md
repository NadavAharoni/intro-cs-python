# תרגיל 6: קלט ופלט

עד עכשיו התוכניות שלנו הדפיסו תמיד את אותו הדבר.
בתרגיל הזה התוכנית תשאל את המשתמש שאלות ותגיב לתשובות שלו.

כתבו כל תוכנית בקובץ נפרד, בתוך תיקיית המפגש.

## חלק א: שלום אישי

צרו קובץ חדש בשם הבא:

```text
greet.py
```

כתבו בו:

```python
name = input("What is your name? ")
print("Hello,", name)
```

הריצו מהטרמינל. התוכנית תעצור ותחכה שתקלידו משהו ותלחצו על אנטר.

### שאלות

1. מה עושה הפקודה לקבלת קלט? מה מופיע על המסך, ולאן הולכת התשובה של המשתמש?
2. למה יש רווח בסוף הטקסט של השאלה? מחקו אותו ובדקו מה משתנה.
3. שנו את התוכנית כך שתשאל גם מאיזו עיר המשתמש, ותדפיס את שתי התשובות במשפט אחד.

## חלק ב: לחבר טקסט

יש כמה דרכים לבנות משפט מכמה חלקים. נסו את שלושתן:

```python
name = "Dana"

print("Hello,", name, "!")
print("Hello, " + name + "!")
print(f"Hello, {name}!")
```

### שאלות

1. מה ההבדל בפלט בין שלוש השורות?
2. בשורה האחרונה יש אות לפני המירכאות. מה קורה אם מוחקים אותה?

## חלק ג: מספרים מהמשתמש

צרו קובץ חדש בשם הבא:

```text
age.py
```

כתבו בו את התוכנית הבאה והריצו אותה:

```python
year = input("What year were you born? ")
age = 2026 - year
print("You are", age, "years old")
```

התוכנית תיכשל. קראו את הודעת השגיאה.

הסיבה: הפקודה לקבלת קלט תמיד מחזירה **טקסט**, גם אם המשתמש הקליד ספרות.
כדי להפוך טקסט למספר שלם, משתמשים בפקודה הבאה:

```python
year = int(input("What year were you born? "))
```

### שאלות

1. תקנו את התוכנית והריצו שוב.
2. מה קורה אם המשתמש מקליד מילה במקום מספר?
3. מה קורה אם המשתמש מקליד מספר עם נקודה עשרונית? איזו פקודה אחרת יכולה לעזור?

   ```python
   float("3.5")
   ```

## חלק ד: סיפור מטורף

כתבו תוכנית שמבקשת מהמשתמש כמה מילים: שם, מקום, חיה, מספר ושם תואר.
אחר כך התוכנית מדפיסה סיפור קצר, שבו המילים האלה משובצות.
למשל:

```text
Name: Dana
Place: Eilat
Animal: penguin
Number: 17
Adjective: purple

Dana went to Eilat and met 17 purple penguins.
```

הריצו את התוכנית כמה פעמים, ונסו גם להכניס תשובות מוזרות.
