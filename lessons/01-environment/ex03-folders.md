# תרגיל 3: בניית מבנה תיקיות

בתרגיל הזה תבנו מבנה תיקיות של פרויקט קטן, בעזרת הטרמינל בלבד.
אסור להשתמש בסייר הקבצים או בעכבר.

---

## חלק א: לתכנן לפני שמקלידים

זה המבנה שצריך לבנות, בתוך תיקיית המפגש של הקורס:

```text
lesson01/
└── led-project/
    ├── README.txt
    ├── src/
    │   ├── main.py
    │   └── helpers.py
    ├── data/
    │   ├── raw/
    │   │   └── measurements.txt
    │   └── processed/
    ├── docs/
    │   └── notes.txt
    └── tests/
```

לפני שמתחילים, כתבו על דף את רשימת הפקודות שלדעתכם תבנה את המבנה.
אחר כך הריצו את הפקודות מהרשימה, אחת אחרי השנייה.

### טיפים

- לפקודה ליצירת תיקייה ולפקודה ליצירת קובץ אפשר לתת כמה שמות בבת אחת:

  ```bash
  mkdir docs tests
  touch a.txt b.txt
  ```

- כדי ליצור כמה רמות של תיקיות בפקודה אחת, מוסיפים את האפשרות הבאה:

  ```bash
  mkdir -p data/raw
  ```

- כדי לראות את כל המבנה, כולל תיקיות פנימיות, מריצים:

  ```bash
  ls -R
  ```

### שאלות

1. כמה פקודות היו ברשימה שכתבתם על הדף? כמה פקודות הייתם צריכים בפועל?
2. האם היו פקודות שנכשלו? למה?
3. מה המספר הכי קטן של פקודות שבו אפשר לבנות את כל המבנה?

---

## חלק ב: להכניס תוכן לקבצים

1. כתבו לקובץ התיאור של הפרויקט שורה אחת שמתארת אותו. למשל:

   ```bash
   echo "LED blinking project" > README.txt
   ```

2. הוסיפו לאותו קובץ שורה שנייה, עם השם שלכם.
3. כתבו לקובץ המדידות שלוש שורות, כל אחת עם מספר אחר.
4. הציגו את התוכן של שני הקבצים, בלי להיכנס לתיקיות שבהן הם נמצאים.

---

## חלק ג: סידור מחדש

הגיעה החלטה לשנות את מבנה הפרויקט. בצעו את השינויים הבאים, מהטרמינל בלבד:

1. שנו את השם של תיקיית התיעוד לשם הבא:

   ```text
   documentation
   ```

2. העבירו את קובץ ההערות מתיקיית התיעוד לתיקייה הראשית של הפרויקט.
3. צרו העתק של קובץ המדידות בתיקייה של הנתונים המעובדים.
4. מחקו את תיקיית הבדיקות.
5. הריצו את הפקודה שמציגה את כל המבנה, וציירו על דף את המבנה החדש.

---

## אתגר

1. בנו את כל המבנה מחלק א בפקודה אחת בלבד.
   רמז: אפשר לחבר כמה פקודות בשורה אחת בעזרת שני סימני "וגם":

   ```bash
   mkdir a && cd a
   ```

2. רמז נוסף: נסו את הפקודה הבאה ובדקו מה היא יוצרת:

   ```bash
   mkdir -p test/{one,two,three}
   ```
