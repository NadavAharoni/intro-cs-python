# תרגיל 2: תנאים ראשונים

עד עכשיו כל התוכניות שלנו ביצעו את כל השורות, לפי הסדר.
משפט תנאי מאפשר לתוכנית להחליט אם לבצע קוד מסוים, לפי ערך של ביטוי אמת או שקר.

```python
temperature = float(input("Temperature: "))

if temperature > 30:
    print("It's hot")
    print("Drink water")
else:
    print("Not too hot")

print("Done")
```

שימו לב לשלושה דברים:

1. בסוף שורת התנאי יש נקודתיים.
2. השורות שתלויות בתנאי מוזחות פנימה, בארבעה רווחים. ההזחה היא חלק מהשפה, ולא רק עיצוב.
3. החלק של "אחרת" הוא לא חובה. השורה האחרונה לא מוזחת, ולכן היא מתבצעת תמיד.

## חלק א: מה יודפס?

**בלי בינה מלאכותית.** לכל קטע, כתבו על דף מה יודפס. אחר כך הריצו ובדקו.

1. קטע ראשון. אחרי הבדיקה, שנו את הערך ל-15 ונחשו שוב:

   ```python

       print("big")
   print("end")
   ```

2. קטע שני:

   ```python
   x = 10
   if x > 10:
       print("A")
   else:
       print("B")
   print("C")
   ```

3. קטע שלישי. שימו לב להזחה:

   ```python
   x = 3
   if x > 10:
       print("A")
       print("B")
   print("C")
   ```

4. קטע רביעי. מה ההבדל מהקטע הקודם?

   ```python
   x = 3

   ```

5. קטע חמישי:

