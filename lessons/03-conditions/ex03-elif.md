# תרגיל 3: יותר משתי אפשרויות

כשיש יותר משתי אפשרויות, משתמשים בשרשרת של תנאים:

```python
if temperature > 30:
    print("Hot")
elif temperature > 20:
    print("Warm")
elif temperature > 10:
    print("Cool")
else:
    print("Cold")
```

פייתון בודק את התנאים מלמעלה למטה. ברגע שתנאי אחד מתקיים, הוא מבצע את הקוד שלו, **ומדלג על כל השאר**.
לכן הסדר של התנאים חשוב.

---

## חלק א: חמש גרסאות

**בלי בינה מלאכותית.**

ציון במבחן הופך לאות לפי הכללים הבאים:

<div dir="rtl">

| ציון | אות |
|---|---|
| 90 ומעלה | <code dir="ltr">A</code> |
| 80 עד 89 | <code dir="ltr">B</code> |
| 70 עד 79 | <code dir="ltr">C</code> |
| 60 עד 69 | <code dir="ltr">D</code> |
| מתחת ל-60 | <code dir="ltr">F</code> |

</div>

לפניכם חמש גרסאות של קוד שאמור לחשב את האות. בכל הגרסאות, המשתנה של הציון הוא מספר שלם בין 0 ל-100.

### גרסה 1

```python
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"
```
