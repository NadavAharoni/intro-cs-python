# תרגיל 6: ביקורת קוד

כלי בינה מלאכותית כותבים קוד שנראה טוב, אבל לפעמים יש בו טעויות קטנות, בדרך כלל בגבולות ובמקרים מיוחדים.
מתכנת טוב יודע לקרוא קוד ולמצוא בו טעויות, עוד לפני שהוא מריץ אותו.

---

## איך עובדים

לכל אחת מהתוכניות הבאות יש תיאור של מה שהיא אמורה לעשות. חלק מהתוכניות נכונות, ובחלק יש טעות אחת או יותר.

**בלי בינה מלאכותית.** לכל תוכנית:

1. קראו את הקוד בלי להריץ אותו.
2. החליטו: האם התוכנית נכונה?
3. אם לא: מצאו קלט שבו היא נותנת תוצאה שגויה, וכתבו מה היא תדפיס ומה הייתה צריכה להדפיס.
4. רק עכשיו הריצו אותה עם הקלט שמצאתם, ובדקו שצדקתם.
5. תקנו את הטעות.

---

## תוכנית 1: כרטיס לקולנוע

ילדים מתחת לגיל 12 משלמים 25 שקלים. מגיל 65 משלמים 30 שקלים. כל השאר משלמים 45 שקלים.

```python
age = int(input("Age: "))
if age < 12:
    price = 25
elif age > 65:
    price = 30
else:
    price = 45
print("Price:", price)
```

## תוכנית 2: זוגי או אי-זוגי

התוכנית מדפיסה אם מספר שלם, חיובי או שלילי, הוא זוגי או אי-זוגי.

```python
n = int(input("Number: "))
if n % 2 == 1:
    print("odd")
else:
    print("even")
```

## תוכנית 3: המקסימום

התוכנית מדפיסה את הגדול מבין שלושה מספרים.

```python
a = int(input("a: "))
b = int(input("b: "))
c = int(input("c: "))
if a > b and a > c:
    biggest = a
elif b > a and b > c:
    biggest = b
else:
    biggest = c
print("Biggest:", biggest)
```

## תוכנית 4: מזג אוויר

מעל 30 מעלות: חם. מעל 20 ועד 30: נעים. 20 ומטה: קר. התוכנית צריכה להדפיס מילה אחת בלבד.

```python
temp = float(input("Temperature: "))
if temp > 30:
    print("Hot")
if temp > 20:
    print("Nice")
else:
    print("Cold")
```

## תוכנית 5: הנחה

קנייה מעל 500 שקלים מקבלת 20 אחוז הנחה. קנייה מעל 100 שקלים מקבלת 10 אחוז הנחה. קנייה קטנה יותר לא מקבלת הנחה.

```python
total = float(input("Total: "))
if total > 100:
    discount = 0.1
elif total > 500:
    discount = 0.2
print("To pay:", total * (1 - discount))
```

## תוכנית 6: שנה מעוברת

שנה היא מעוברת אם היא מתחלקת ב-4 אבל לא ב-100, או אם היא מתחלקת ב-400.

```python
year = int(input("Year: "))
if year % 4 == 0 and year % 100 != 0 or year % 400 == 0:
    print("leap year")
else:
    print("not a leap year")
```

## תוכנית 7: כניסה למערכת

המשתמש נכנס אם שם המשתמש הוא admin והסיסמה היא 1234.

```python
user = input("User: ")
password = input("Password: ")
if user == "admin" or password == "1234":
    print("Welcome")
else:
    print("Access denied")
```

## תוכנית 8: טעינת סוללה

עד 20 אחוז: נמוכה. מעל 20 ועד 80: תקינה. מעל 80: מלאה. ערך מחוץ לטווח של 0 עד 100: שגיאה.

```python
level = int(input("Battery %: "))
if level < 0 or level > 100:
    print("Error")
elif level <= 20:
    print("Low")
elif level <= 80:
    print("OK")
else:
    print("Full")
```
