# תרגיל 10: לפשט תנאים

תרגיל בונוס. קוד עם תנאים נוטה להסתבך. תנאי פשוט יותר קל יותר לקריאה, ויש בו פחות מקום לטעויות.
אבל כשמפשטים, צריך לוודא שהקוד החדש עושה **בדיוק** את מה שעשה הישן.

---

## חלק א: לפשט

**בלי בינה מלאכותית.** כתבו גרסה פשוטה יותר לכל אחד מהקטעים הבאים, שעושה בדיוק את אותו הדבר.

1. קטע ראשון:

   ```python
   if is_ready == True:
       print("Go")
   ```

2. קטע שני:

   ```python
   if x > 0:
       positive = True
   else:
       positive = False
   ```

3. קטע שלישי:

   ```python
   if age >= 18:
       if has_ticket:
           print("Enter")
   ```

4. קטע רביעי:

   ```python
   if not (x <= 0 or x >= 10):
       print("In range")
   ```

5. קטע חמישי:

   ```python
   if x > 10:
       print("big")
   elif x <= 10 and x > 5:
       print("medium")
   elif x <= 5:
       print("small")
   ```

6. קטע שישי:

   ```python
   if rain:
       take_umbrella = True
   elif not rain and cloudy:
       take_umbrella = True
   else:
       take_umbrella = False
   ```

## חלק ב: להוכיח שקילות

כשהקלט הוא כמה משתנים של אמת ושקר, אפשר לבדוק את **כל** האפשרויות. עם שני משתנים יש ארבעה צירופים, ועם שלושה יש שמונה.

**בלי בינה מלאכותית.**

1. לקטע השישי, כתבו טבלה עם כל ארבעת הצירופים של שני המשתנים. בדקו שהגרסה שלכם והגרסה המקורית נותנות את אותה תוצאה בכל שורה.
2. האם שני הביטויים הבאים שקולים? בדקו בעזרת טבלה עם שמונה שורות.

   ```python
   a and (b or c)
   (a and b) or c
   ```
