## חלק ד: עיצוב של מחרוזות

במפגש הקודם ראינו מחרוזות שמתחילות באות f, שבהן אפשר לשלב משתנים בתוך סוגריים מסולסלים.
בתוך הסוגריים אפשר לכתוב כל ביטוי, ולא רק שם של משתנה:

```python
a = 7
b = 3
print(f"{a} + {b} = {a + b}")
print(f"{a} / {b} = {a / b}")
```

אחרי נקודתיים בתוך הסוגריים אפשר לקבוע איך הערך יוצג. נסו:

```python
x = 2 / 3
print(f"{x}")
print(f"{x:.2f}")
print(f"{x:.4f}")
print(f"{x:.1%}")

big = 1234567
print(f"{big:,}")

n = 42
print(f"[{n:5}]")
print(f"[{n:05}]")

name = "Dana"
print(f"[{name:10}]")
print(f"[{name:>10}]")
print(f"[{name:^10}]")
```

### שאלות

1. מה עושה הצירוף של נקודה, ספרה ואות, אחרי הנקודתיים?
2. מה עושה מספר שמופיע לבד אחרי הנקודתיים?
3. מה עושים סימני גדול-מ, קטן-מ והגג? למה כל אחד מהם יכול להתאים?
4. מה עושה האפס לפני רוחב השדה?
