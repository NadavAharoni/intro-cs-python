# מפגש 2: משתנים, טיפוסים וביטויים

## מטרות המפגש

בסוף המפגש תדעו:

- לפתוח חשבון בגיטהאב ולהשתמש בקופיילוט בתוך העורך.
- להבין מה קורה בפעולת השמה, ולעקוב אחרי ערכים של משתנים.
- להכיר את הטיפוסים הבסיסיים, ולהמיר ביניהם.
- לכתוב ביטויים חשבוניים וביטויי השוואה, ולהבין את סדר הפעולות.
- לעבוד עם מחרוזות ולהדפיס פלט מעוצב.
- לכתוב תוכניות שמקבלות קלט, מחשבות ומדפיסות תוצאה.
