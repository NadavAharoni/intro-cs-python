# תרגיל 11: לבדוק תוכניות בלי להקליד

תרגיל בונוס שמחבר בין הטרמינל לפייתון.

כשבודקים תוכנית שמבקשת כמה קלטים, מעייף להקליד אותם שוב ושוב בכל הרצה.
אפשר לשמור את הקלטים בקובץ, ולתת לטרמינל להזין אותם לתוכנית.

---

## חלק א: קלט מקובץ

1. צרו קובץ טקסט עם הקלטים של התוכנית לחלוקת חשבון מתרגיל 6, כל קלט בשורה נפרדת:

   ```bash
   printf "340\n12\n4\n" > bill_input.txt
   cat bill_input.txt
   ```

2. הריצו את התוכנית, כשהקלט מגיע מהקובץ:

   ```bash
   python bill.py < bill_input.txt
   ```

### שאלות

1. מה עושה סימן קטן-מ בפקודה?
2. איך נראה הפלט? למה הקלטים עצמם לא מופיעים על המסך?

---

## חלק ב: קלט מצינור

אפשר גם להעביר קלט לתוכנית בעזרת צינור:

```bash
echo 100 | python temperature.py
printf "10000\n" | python duration.py
```

---

## חלק ג: קבצי בדיקה

1. לכל אחת מהתוכניות שכתבתם בתרגיל 6, צרו שני קבצי קלט לפחות:
   - אחד עם הקלט מהדוגמה בתרגיל.
   - אחד עם קלט שבחרתם, שהתוצאה שלו ידועה לכם מראש.
2. הריצו כל תוכנית עם כל קובץ, ובדקו שהפלט נכון.
3. שמרו את הפלט של כל הרצה לקובץ, בעזרת הפניה של הפלט:

   ```bash
   python bill.py < bill_input.txt > bill_output.txt
   ```

---

## חלק ד: קלט לא תקין

צרו קובץ קלט עם ערכים בעייתיים לתוכנית החשבון, למשל:

- מספר אנשים שהוא אפס.
- טקסט במקום מספר.
- מספר שלילי.

### שאלות

1. מה קורה בכל מקרה?
2. אילו מהמקרים גורמים לשגיאה, ואילו נותנים תוצאה שגויה בלי שגיאה?
3. במפגש הבא נלמד תנאים. איך לדעתכם הם יעזרו כאן?
