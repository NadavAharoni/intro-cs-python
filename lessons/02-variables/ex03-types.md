# תרגיל 3: טיפוסים והמרות

לכל ערך בפייתון יש **טיפוס**, שקובע מה הערך מייצג ואילו פעולות אפשר לעשות איתו.
בתרגיל הזה נכיר ארבעה טיפוסים בסיסיים:

<div dir="rtl">

| טיפוס | מה הוא מייצג | דוגמאות |
|---|---|---|
| <code dir="ltr">int</code> | מספר שלם | <code dir="ltr">7</code>, <code dir="ltr">-3</code>, <code dir="ltr">0</code> |
| <code dir="ltr">float</code> | מספר עשרוני | <code dir="ltr">3.14</code>, <code dir="ltr">-0.5</code>, <code dir="ltr">2.0</code> |
| <code dir="ltr">str</code> | טקסט, שנקרא מחרוזת | <code dir="ltr">"hello"</code>, <code dir="ltr">'42'</code> |
| <code dir="ltr">bool</code> | אמת או שקר | <code dir="ltr">True</code>, <code dir="ltr">False</code> |

</div>

---

## חלק א: מה הטיפוס?

הפקודה הבאה מחזירה את הטיפוס של ערך:

```python
type(7)
```

לפני שמריצים, נחשו את הטיפוס של כל אחד מהערכים הבאים. אחר כך בדקו במצב האינטראקטיבי.

```python
type(7)
type(7.0)
type("7")
type(True)
type("True")
type(10 / 2)
type(10 // 2)
type(2 ** 10)
type(2.0 ** 10)
type(3 + 0.5)
```

### שאלות

1. מה הטיפוס של תוצאת חילוק רגיל, גם כשהחילוק "יוצא שלם"?
2. מה הטיפוס של תוצאה כשמחברים מספר שלם ומספר עשרוני?
3. מה ההבדל בין הערך הרביעי לחמישי ברשימה?

---

## חלק ב: המרות

לכל טיפוס יש פקודה בשם שלו, שממירה ערך לטיפוס הזה. נחשו ובדקו:

```python
int("42")
int(3.99)
int(-3.99)
float("2.5")
float(7)
str(42)
str(3.5) + "V"
int("3.5")
int(" 12 ")
int("12a")
round(3.99)
round(2.5)
round(3.5)
round(3.14159, 2)
```

### שאלות

1. האם ההמרה של מספר עשרוני לשלם מעגלת אותו? מה היא עושה בדיוק?
2. איך אפשר להמיר את הטקסט הבא למספר שלם? רמז: בשני שלבים.

   ```python
   "3.5"
   ```

3. תוצאות העיגול של 2.5 ושל 3.5 מפתיעות. חפשו ברשת מה זה "עיגול בנקאי".

## חלק ג: אמת ושקר

לכל ערך יש "ערך אמת". נחשו ובדקו:

```python
bool(1)
bool(0)
bool(-5)
bool(0.0)
bool("hello")
bool("")
bool(" ")
bool("False")
```

### שאלות

1. אילו ערכים נחשבים לשקר? נסחו כלל.
2. למה ההמרה של הטקסט האחרון נותנת אמת?

## חלק ד: פעולות בין טיפוסים

חלק מהפעולות עובדות בין טיפוסים שונים, וחלק לא. נחשו ובדקו:

```python
3 + 4
"3" + "4"
"3" * 4
3 * "4"
"3" + 4
"3" * "4"
3 + True
True + True
```

### שאלות

1. מה עושה חיבור של שתי מחרוזות? ומה עושה כפל של מחרוזת במספר?
2. איזו פעולה נכשלה, ומה הודעת השגיאה?
3. איך הייתם מתקנים את השורה החמישית כך שהתוצאה תהיה 7? ואיך כך שהתוצאה תהיה 34?
4. מה הערך המספרי של אמת?

## חלק ה: הבאג של הקלט

התוכנית הבאה אמורה לחבר שני מספרים. הריצו אותה עם המספרים 2 ו-3.

```python
a = input("First number: ")
b = input("Second number: ")
print("The sum is", a + b)
```

### שאלות

1. מה הודפס? למה?
2. תקנו את התוכנית כך שתעבוד גם עם מספרים עשרוניים.
3. הוסיפו שורה שמדפיסה את הטיפוס של כל אחד מהמשתנים, לפני ואחרי התיקון.
