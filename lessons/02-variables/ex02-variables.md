# תרגיל 2: משתנים והשמה

משתנה הוא שם שמצביע על ערך שנשמר בזיכרון.
פעולת ההשמה, עם סימן שווה יחיד, נותנת למשתנה ערך.

---

## חלק א: השמה היא לא שוויון

במתמטיקה, המשוואה הבאה לא הגיונית. בפייתון היא חוקית לגמרי:

```python
x = x + 1
```

בפייתון, סימן השווה אומר: "חשב את מה שמימין, ושמור את התוצאה בשם שמשמאל".

### שאלות

לפני שמריצים, נחשו מה כל קטע מדפיס. אחר כך בדקו במצב האינטראקטיבי.

1. קטע ראשון:

   ```python
   x = 5
   x = x + 1
   print(x)
   ```

2. קטע שני:

   ```python
   a = 3
   b = a
   a = 10
   print(a, b)
   ```

3. קטע שלישי:

   ```python
   n = 2
   n = n * n
   n = n * n
   print(n)
   ```

4. קטע רביעי:

   ```python
   y = 7
   7 = y
   ```

4. שימו לב לחצים שמחברים כל שם לערך שלו.

## חלק ג: מעקב

בכל אחד מהקטעים הבאים, מלאו טבלה עם הערך של כל משתנה אחרי כל שורה. אם למשתנה עוד אין ערך, השאירו ריק.
בסוף בדקו את התשובה שלכם בעזרת האתר מחלק ב.

1. קטע ראשון:

   ```python
   a = 4
   b = a * 2
   a = b - 1
   b = a + b
   c = a + b
   ```

2. קטע שני:

   ```python
   total = 0
   total = total + 10
   total = total + 20
   count = 2
   ```

   מה הערך של הממוצע בסוף? האם הוא השתנה כשאיפסנו את הסכום בשורה האחרונה? למה?

נסו כל אחת מההשמות הבאות במצב האינטראקטיבי. אילו מהן חוקיות?

```python

```

### שאלות

1. נסחו את הכללים: אילו תווים מותר להשתמש בהם בשם של משתנה, ובאיזה תו אסור להתחיל?
2. האם יש הבדל בין שני המשתנים הראשונים? בדקו.
3. למה ההשמה לשם הבא נכשלה? חפשו מה זה "מילה שמורה" בפייתון.


### מוסכמה

בפייתון נהוג לכתוב שמות של משתנים באותיות קטנות, עם קו תחתון בין מילים:


בחרו שמות שמסבירים מה המשתנה מכיל. השם הראשון בדוגמה הבאה טוב יותר מהשני:

## חלק ה: קיצורים

יש קיצור לפעולות שמעדכנות משתנה על בסיס הערך הקודם שלו:

```python
score = 10
score += 5     # same as: score = score + 5
score -= 3     # same as: score = score - 3
score *= 2     # same as: score = score * 2
print(score)
```

### שאלות

1. נחשו מה יודפס, ובדקו.
2. האם יש גם קיצור לחילוק? ולחילוק שלם? בדקו.

---

## חלק ו: החלפה

נתונים שני משתנים:

```python
a = 5
b = 8
```

1. כתבו קוד שמחליף בין הערכים, כך שבסוף הערך של הראשון יהיה 8 והערך של השני יהיה 5.
   רמז: מה קורה אם כותבים פשוט את שתי השורות הבאות? למה זה לא עובד?

   ```python
   a = b
   b = a
   ```

2. בפייתון יש דרך קצרה לעשות את זה בשורה אחת. נסו:

   ```python
   a, b = b, a
   ```
