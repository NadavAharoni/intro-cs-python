## חלק ב: פעולות על ביטים

<div dir="rtl">

| סימן | פעולה |
|---|---|
| <code dir="ltr">&amp;</code> | וגם, ביט אחרי ביט |
| <code dir="ltr">&#124;</code> | או, ביט אחרי ביט |
| <code dir="ltr">^</code> | או בלעדי, ביט אחרי ביט |
| <code dir="ltr">~</code> | היפוך כל הביטים |
| <code dir="ltr">&lt;&lt;</code> | הזזה שמאלה |
| <code dir="ltr">&gt;&gt;</code> | הזזה ימינה |

</div>

נחשו את התוצאה בבינארי, ובדקו:

```python
a = 0b1100
b = 0b1010
print(f"{a & b:04b}")
print(f"{a | b:04b}")
print(f"{a ^ b:04b}")
print(f"{a << 1:05b}")
print(f"{a >> 2:04b}")
print(1 << 10)
```

### שאלות

1. מה עושה הזזה שמאלה במקום אחד, מבחינה חשבונית? ומה עושה הזזה ימינה?
2. למה ההזזה של 1 בעשרה מקומות שמאלה נותנת 1024?

## חלק ג: אוגר

נניח שמשתנה מייצג אוגר של 8 ביטים במיקרו-בקר. הביטים ממוספרים מ-0, הביט הימני, עד 7.

```python
register = 0b10010110
```

1. בדיקה אם ביט מספר 4 דולק. התוצאה צריכה להיות 1 או 0.
2. הדלקת ביט מספר 0, בלי לשנות את שאר הביטים.
3. כיבוי ביט מספר 7, בלי לשנות את שאר הביטים.
4. היפוך ביט מספר 3.
5. חילוץ ארבעת הביטים העליונים, כמספר בין 0 ל-15.
