# תרגיל 1: חשבון גיטהאב וקופיילוט

גיטהאב הוא אתר שבו מתכנתים שומרים ומשתפים קוד. חומרי הקורס נמצאים שם.
עם חשבון בגיטהאב מקבלים גם גישה חינמית לקופיילוט, כלי בינה מלאכותית שמציע השלמות קוד בתוך העורך.

---

## חלק א: יצירת חשבון

1. היכנסו לאתר:

   ```text
   https://github.com/signup
   ```

2. מלאו את הפרטים: כתובת דואר, סיסמה ושם משתמש.
3. אשרו את כתובת הדואר בעזרת הקוד שיישלח אליכם.

### טיפים לבחירת הפרטים

- **כתובת דואר:** עדיף להשתמש בכתובת פרטית ולא בכתובת של המכללה, כדי שהחשבון יישאר שלכם גם אחרי הלימודים. את כתובת המכללה אפשר להוסיף בהמשך.
- **שם משתמש:** השם יופיע בכתובת של כל הקוד שתפרסמו. בחרו שם שתרצו להציג גם למעסיק, למשל על בסיס השם שלכם.
- **אימות דו-שלבי:** גיטהאב עשוי לבקש להפעיל אימות דו-שלבי. אפשר להשתמש באפליקציית אימות בטלפון. שמרו את קודי השחזור במקום בטוח.

---

## חלק ב: קופיילוט בעורך

1. פתחו את העורך.
2. בשורת המצב, בתחתית החלון, יש סמל של קופיילוט. העבירו עליו את העכבר ובחרו:

   ```text
   Use AI Features
   ```

3. בחרו להתחבר עם חשבון גיטהאב. ייפתח דפדפן. אשרו שם את החיבור.
4. אם אין לכם עדיין מנוי, החשבון יצורף אוטומטית לתוכנית החינמית.

התוכנית החינמית כוללת מספר מוגבל של השלמות קוד בכל חודש. זה מספיק לקורס.

---

## חלק ג: לנסות

1. צרו קובץ חדש בשם הבא:

   ```text
   copilot_test.py
   ```

2. כתבו בו את ההערה הבאה, ולחצו על אנטר בסופה:

   ```python
   # ask the user for a temperature in Celsius and print it in Fahrenheit
   ```

3. אחרי רגע תופיע הצעה בצבע אפור. כדי לקבל אותה, לחצו על טאב. כדי לדחות אותה, לחצו על אסקייפ.
4. המשיכו לקבל הצעות עד שהתוכנית שלמה, והריצו אותה.

### שאלות

1. האם התוכנית שקופיילוט כתב נכונה? בדקו אותה עם 100 מעלות, שהן 212 פרנהייט, ועם 0 מעלות, שהן 32 פרנהייט.
2. האם הבנתם כל שורה בקוד שהוצע? אם לא, מה לא ברור?
3. מחקו את הקוד, ונסו לכתוב הערה אחרת שמתארת תוכנית אחרת. האם ההצעה תאמה את מה שרציתם?

---

## הערה על שימוש בקופיילוט

קופיילוט טועה לפעמים, גם כשהקוד שלו נראה משכנע. בכל פעם שאתם מקבלים הצעה, ודאו שאתם מבינים אותה ושהיא עושה מה שצריך.
בהצגה בסוף המפגש תצטרכו להסביר כל שורה בקוד שלכם, גם שורות שקופיילוט כתב.

אם ההצעות מפריעות לכם, אפשר לכבות אותן זמנית. לחצו על סמל קופיילוט בשורת המצב, ובחרו באפשרות לכבות או להשהות את ההשלמות.

---

## בונוס: הטבות לסטודנטים

סטודנטים יכולים לקבל בחינם תוכנית מורחבת של קופיילוט, עם השלמות קוד ללא הגבלה.
כדי לקבל אותה, צריך להירשם לתוכנית של גיטהאב לסטודנטים:

```text
https://education.github.com
```

- תצטרכו להוכיח שאתם סטודנטים, למשל בעזרת כתובת הדואר של המכללה או צילום של כרטיס סטודנט.
- האישור יכול לקחת כמה ימים. עד אז אפשר להמשיך עם התוכנית החינמית.
