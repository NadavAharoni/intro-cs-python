# תרגיל 6: קלט, חישוב, פלט

רוב התוכניות הפשוטות בנויות משלושה שלבים:

1. **קלט:** מקבלים נתונים מהמשתמש.
2. **חישוב:** מחשבים משהו מהנתונים.
3. **פלט:** מדפיסים את התוצאה בצורה ברורה.

כתבו כל תוכנית בקובץ נפרד, בתיקייה חדשה של המפגש:

```bash
mkdir ~/intro-cs/lesson02
cd ~/intro-cs/lesson02
```

לכל תוכנית מופיעה דוגמה להרצה. התוכנית שלכם צריכה להדפיס פלט באותו מבנה.
בדקו כל תוכנית עם כמה קלטים שונים, ולא רק עם הדוגמה.

---

## תוכנית 1: טמפרטורה

קובץ:

```text
temperature.py
```

התוכנית מקבלת טמפרטורה במעלות צלזיוס, ומדפיסה אותה בפרנהייט ובקלווין, עם ספרה אחת אחרי הנקודה.

```text
F = C * 9 / 5 + 32
K = C + 273.15
```

```text
Temperature in Celsius: 36.6
Fahrenheit: 97.9
Kelvin: 309.8
```

---

## תוכנית 2: חלוקת חשבון

קובץ:

```text
bill.py
```

קבוצת חברים יצאה לאכול. התוכנית מקבלת את הסכום הכולל, את אחוז הטיפ ואת מספר האנשים, ומדפיסה כמה כל אחד משלם.

```text
Total bill: 340
Tip percent: 12
Number of people: 4
Tip: 40.80
Total with tip: 380.80
Each person pays: 95.20
```

---

## תוכנית 3: זמן

קובץ:

```text
duration.py
```

התוכנית מקבלת מספר שניות, ומדפיסה אותו בפורמט של שעות, דקות ושניות, כשלדקות ולשניות יש תמיד שתי ספרות.

```text
Seconds: 10000
2:46:40
```

```text
Seconds: 3605
1:00:05
```

---

## תוכנית 4: ספרות

קובץ:

```text
digits.py
```

התוכנית מקבלת מספר שלם בן שלוש ספרות, ומדפיסה כל ספרה בנפרד, את סכום הספרות, ואת המספר בסדר הפוך.
השתמשו רק בפעולות חשבון. אל תתייחסו למספר כמחרוזת.

```text
Three-digit number: 472
Hundreds: 4
Tens: 7
Units: 2
Sum of digits: 13
Reversed: 274
```

## תוכנית 5: עודף

קובץ:

```text
change.py
```

התוכנית מקבלת סכום שלם בשקלים, ומחשבת איך לתת אותו במספר המינימלי של שטרות ומטבעות.
השטרות והמטבעות האפשריים: 200, 100, 50, 20, 10, 5, 2, 1.

```text
Amount: 387
200: 1
100: 1
50: 1
20: 1
10: 1
5: 1
2: 1
1: 0
```

רמז: אחרי כל שטר, חשבו כמה כסף נשאר.

## תוכנית 6: מהירות ממוצעת

קובץ:

```text
speed.py
```

התוכנית מקבלת מרחק בקילומטרים וזמן נסיעה בשעות ובדקות, ומדפיסה את המהירות הממוצעת בקמ"ש ובמטרים לשנייה.

```text
Distance (km): 150
Hours: 1
Minutes: 40
Average speed: 90.0 km/h
Average speed: 25.0 m/s
```
