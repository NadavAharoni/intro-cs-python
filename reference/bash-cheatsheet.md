# דף עזר: פקודות הטרמינל

## מקומות מיוחדים

| סימן | משמעות |
|---|---|
| `~` | תיקיית הבית |
| `.` | התיקייה הנוכחית |
| `..` | התיקייה שמעל התיקייה הנוכחית |
| `/` | שורש מערכת הקבצים |
| `/c` | הכונן הראשי של חלונות |

## ניווט

| פקודה | מה היא עושה |
|---|---|
| `pwd` | מדפיסה את התיקייה הנוכחית |
| `ls` | מציגה את תוכן התיקייה |
| `ls -l` | תצוגה מפורטת |
| `ls -a` | כולל קבצים מוסתרים |
| `ls -R` | כולל כל התיקיות הפנימיות |
| `cd folder` | עוברת לתיקייה |
| `cd ..` | עולה תיקייה אחת למעלה |
| `cd ~` | חוזרת לתיקיית הבית |
| `cd -` | חוזרת לתיקייה הקודמת |

## קבצים ותיקיות

| פקודה | מה היא עושה |
|---|---|
| `mkdir name` | יוצרת תיקייה |
| `mkdir -p a/b/c` | יוצרת כמה רמות של תיקיות |
| `touch file.txt` | יוצרת קובץ ריק |
| `cp src dst` | מעתיקה קובץ |
| `cp -r src dst` | מעתיקה תיקייה |
| `mv src dst` | מעבירה או משנה שם |
| `rm file` | מוחקת קובץ, לצמיתות |
| `rmdir folder` | מוחקת תיקייה ריקה |
| `rm -r folder` | מוחקת תיקייה עם כל התוכן. זהירות! |

## תוכן של קבצים

| פקודה | מה היא עושה |
|---|---|
| `cat file` | מציגה את כל הקובץ |
| `head file` | מציגה את תחילת הקובץ |
| `tail file` | מציגה את סוף הקובץ |
| `wc -l file` | סופרת שורות |
| `grep text file` | מציגה שורות שמכילות טקסט |
| `echo "text" > file` | כותבת לקובץ, ומוחקת את מה שהיה בו |
| `echo "text" >> file` | מוסיפה לסוף הקובץ |
| `a \| b` | מעבירה את הפלט של פקודה אחת לפקודה הבאה |

## כלים

| פקודה | מה היא עושה |
|---|---|
| `python file.py` | מריצה תוכנית פייתון |
| `python` | נכנסת למצב האינטראקטיבי של פייתון |
| `code .` | פותחת את התיקייה הנוכחית בעורך |
| `explorer .` | פותחת את התיקייה הנוכחית בסייר הקבצים |
| `clear` | מנקה את המסך |
| `history` | מציגה את הפקודות האחרונות |
| `command --help` | מציגה הסבר על פקודה |

## מקשים

| מקש | מה הוא עושה |
|---|---|
| `Tab` | משלים שם של קובץ או פקודה |
| `↑` | מחזיר את הפקודה הקודמת |
| `Ctrl+C` | עוצר פקודה או תוכנית שרצה |
