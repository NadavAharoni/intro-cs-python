# מבוא למדעי המחשב ושפת Python

ברוכים הבאים לקורס!
זהו קורס מבוא לתכנות, שמתחיל מהבסיס ממש. לא נדרש ידע קודם בתכנות.

## איך הקורס עובד

- בקורס יש 13 מפגשים, פעם בשבוע.
- רוב הזמן במפגש מוקדש לעבודה מעשית בכיתה, בזוגות.
- בסוף כל מפגש אחד הסטודנטים מציג את מה שהזוג עשה. ההצגות הן חלק מהציון הסופי.
- בכל מפגש יש יותר תרגילים ממה שאפשר לסיים. אין צורך לסיים הכל, אבל כדאי להתקדם כמה שיותר.

## עבודה בזוגות

אנחנו עובדים בשיטת "נהג ונווט":

- **הנהג** יושב מול המקלדת ומקליד.
- **הנווט** קורא את התרגיל, חושב על הצעד הבא, ושם לב לטעויות.
- מחליפים תפקידים בכל תרגיל חדש, או כל 20 דקות בערך.

שני בני הזוג צריכים להבין כל דבר שנכתב. אם רק אחד מבין, עצרו והסבירו זה לזה.
