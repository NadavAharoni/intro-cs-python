# בוחני תרגול

בקורס יהיו בחנים קצרים, **בלי מחשב ובלי כלי בינה מלאכותית**.
הבחנים בודקים הבנה: לקרוא קוד ולדעת מה הוא עושה, למצוא טעויות, ולכתוב תוכניות קצרות בעצמכם.

הבוחנים כאן הם לתרגול בלבד, ולא נכנסים לציון.

## איך לתרגל

1. הדפיסו את הבוחן, או פתחו אותו והחזיקו דף ועט לידכם.
2. קבעו שעון לזמן שמופיע בראש הבוחן.
3. ענו על הכל בלי מחשב, בלי הרצה ובלי עזרה.
4. רק אחרי שסיימתם, פתחו את קובץ התשובות ובדקו.
5. על כל טעות: הריצו את הקוד, והבינו למה טעיתם. כאן מותר, ואפילו מומלץ, להיעזר בכלי בינה מלאכותית.
